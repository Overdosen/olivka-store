# Товари та складський облік (Products)

Товарний асортимент інтернет-магазину **Store Olivka** представляє собою естетичний та натуральний одяг для немовлят. Усі дані про товари зберігаються в таблиці `public.products` бази даних Supabase та керуються через спеціальні інтерфейси в CRM-панелі адміністратора.

## Key Points

- **Два типи обліку залишків**: Підтримується облік товарів як з розмірною сіткою (наприклад, 56, 62, 68 розміри), так і безрозмірних товарів (аксесуари, іграшки тощо), де залишки контролюються в одному загальному полі `stock`.
- **Автоматичне списання замовлень**: Завдяки тригерам бази даних Postgres, при успішному оформленні замовлення залишки відповідних товарів та розмірів автоматично списуються.
- **Інтеграція з Google Merchant Center**: Товари автоматично синхронізуються через скрипт Membrane для відображення в Google Shopping з актуальними цінами та наявністю.
- **SEO-оптимізація**: Кожна картка товару підтримує кастомні мета-теги (title, description), які безпосередньо впливають на пошукове ранжування сторінок товарів.
- **Зв'язок з категоріями**: Товари прив'язані до категорій за допомогою зовнішнього ключа `category_id`.

## Details

### 1. Структура Даних Товарів
У базі даних Supabase таблиця `products` містить:
* `id` (bigint, primary key) — Унікальний ідентифікатор товару.
* `title` (text) — Назва товару для відображення на сайті.
* `price` (numeric) — Роздрібна вартість товару.
* `compare_at_price` (numeric, optional) — Стара ціна для відображення знижки.
* `images` (array) — Список посилань на зображення товару в Supabase Storage.
* `sizes` (jsonb, optional) — Словник розмірів та відповідної кількості в наявності `{ "56": 5, "62": 2 }`.
* `stock` (integer) — Залишок товару на складі для безрозмірних позицій.
* `cogs` (numeric) — Собівартість товару (Cost of Goods Sold) для фінансового аналізу прибутку.

### 2. Складський контроль у CRM
CRM-панель містить сторінку редагування товарів `/admin/products/[id]`, яка дозволяє:
1. Задавати окремо кількість одиниць для кожного розміру, якщо у товару є розмірна сітка.
2. Керувати загальним полем "Кількість на складі (Без розмірів)" для аксесуарів чи інших товарів без розмірів, що гарантує гнучкість у роботі менеджерів.
3. Прораховувати загальну вартість складу та капітал на основі собівартості (`cogs`) кожного товару для складання звітів про капітал.
