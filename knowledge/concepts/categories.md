# Категорії товарів (Categories)

Категорії в інтернет-магазині **Store Olivka** слугують для логічного групування та структурування товарного асортименту, полегшуючи клієнтам пошук ніжного одягу для немовлят на головній сторінці та в каталозі.

## Key Points

- **Ієрархія та навігація**: Товари розподіляються за гендерними ознаками ("для дівчаток", "для хлопчиків") та типами одягу ("комплекти", "боді", "аксесуари").
- **Унікальні SEO описи**: Кожна категорія підтримує кастомний SEO-опис та заголовок, що зберігаються в базі даних для оптимізації пошукового ранжування.
- **Динамічний каталог**: Сторінки категорій генеруються динамічно на основі `catId` у шляху `/category/[catId]` та відображають лише релевантний асортимент товарів.
- **CRM-панель керування**: Адміністратори можуть швидко створювати нові категорії, змінювати їх черговість, додавати банери та редагувати SEO-метадані на сторінці `/admin/categories`.

## Details

### 1. Структура Таблиці Категорій
Таблиця `public.categories` у Supabase спроектована для оптимальної SEO-інтеграції та містить:
* `id` (bigint, primary key) — Ідентифікатор категорії (використовується в URL як `catId`, наприклад `/category/baby-sets`).
* `name` (text) — Назва категорії, що відображається в меню та заголовках.
* `description` (text) — Докладний опис категорії, який виводиться у верхній частині сторінки каталогу.
* `seo_title` (text) — Спеціальний заголовок для мета-тегів сторінки категорії.
* `seo_description` (text) — Унікальний мета-опис категорії для пошукових систем Google.
* `image_url` (text) — Посилання на обкладинку категорії для навігаційних карток на головній сторінці.

### 2. SEO та WWW-транзиція
Під час переходу на єдиний домен без WWW (`olivka.store`) та оптимізації канонічних посилань, сторінки категорій були переведені на динамічну генерацію метаданих. Next.js використовує функцію `generateMetadata` для отримання SEO-заголовків категорій безпосередньо з Supabase при кожному запиті, що гарантує 100% відповідність вимогам пошукової індексації.
